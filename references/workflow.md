# Workflow

## 1. Clarify

Ask in small rounds rather than a long questionnaire. Resolve:

- exact concept and possible multiple meanings;
- core reader and assumed knowledge;
- learning outcome;
- desired tone and visual direction;
- page-count tolerance;
- whether references or a recurring IP character are required;
- PNG-only versus editable source delivery.

If the user gives enough context, summarize assumptions and continue. Stop for clarification only when ambiguity would materially change the explanation.

Remind the user to upload style references if the style is still undecided.

## 2. Verify

For AIGC, LLM, Agent, RAG, and similar terms, cross-check:

1. What it is.
2. Why it matters or works.
3. How it is used or built.
4. Important limitations or common misconceptions.

Prefer primary technical documentation and multiple independent reliable sources. Separate simplified analogy from literal mechanism. Do not imply that prediction alone guarantees truth.

## 3. Plan the narrative

Use a short story arc:

1. Cover: create curiosity.
2. Definition: one-sentence plain-language answer.
3. Mechanism: show the minimum causal chain.
4. Capability/use: show concrete branches or scenarios.
5. Limitation: close with a memorable boundary.

Add pages only when each adds a distinct learning step. Confirm the exact count before image generation.

## 4. Draft copy

For each page define:

- page purpose;
- exact headline;
- exact explanation;
- visual metaphor or machine scene;
- emphasized orange words;
- text that must appear inside the illustration.

Freeze exact text before generating images. Keep sentences short and conversational.

## 5. Generate and revise

- Generate the cover first and obtain approval.
- Generate one content page at a time.
- Use the last approved page as the layout/color master for later pages.
- Treat annotated screenshots as precise edit instructions.
- When the user says “其他不动”, list invariants in the edit prompt and preserve them aggressively.
- After generation, check Chinese characters, punctuation, labels, page dimensions, and clipping.
- If only scale or position is wrong, request a single targeted edit; do not redesign the scene.

## 6. Final QA

Compare all pages side by side:

- headline top and left edges;
- per-character headline size and weight;
- orange hue, saturation, and brightness;
- corner-label position and scale;
- background temperature;
- machine material and lighting;
- explanation-panel width and style;
- visual density and breathing room;
- filename sequence and 1086 × 1448 dimensions.

Create a clean final folder. Preserve earlier versions elsewhere.
